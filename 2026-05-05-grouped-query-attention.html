I

KV cache 这笔税

上一课算过 KV cache 的开销：每多一个 token、每多一层、每多一个 KV head，都要在 HBM 里再开一块 K 和一块 V 的格子。Decode 阶段每出一个 token 都要把这堆 K、V 全部读一遍——它就是 decode-bound 的根因。

把那条公式重新写出来，但这次把视角放在头数上：

公式 bytes/token = 2 · n_layers · n_kv_heads · head_dim · dtype_bytes

注意一件事：左边的 n_kv_heads，不是 n_query_heads。在最朴素的 MHA 里这俩相等，所以人们经常混着说。一旦它们能不相等，KV cache 就出现了一个可以被工程师切的旋钮。Multi-Query 和 Grouped-Query Attention 做的就是这件事：把 query 头保留，把 KV 头压下来。

下面分三步看：先把三种接线方式画清楚，再用一个滑块把节省的显存感受清楚，最后讲为什么这种"偷工减料"在实测里几乎没掉点。

II

三种接线方式

把 attention 想成两边的连线：上边是 query 头（每个 token 都要"问问题"的），下边是 KV 头（被读取的"世界状态"）。MHA、MQA、GQA 的全部区别，就是这堆连线该怎么连。

观察 GQA 是中庸：把 query 头分成若干 group，每个 group 共享一份 K、V。MHA（一对一）和 MQA（多对一）都是它的端点。

把它放进一台 80 GB 的 H100：MHA 时一条 8K 的请求要吃掉 20 GiB KV cache，留给权重和 activation 已所剩无几；GQA-8 的同一条请求只占 2.5 GiB，等于把并发批数直接抬高 8 倍，throughput 跟着跳。

关键直觉 KV cache 的体积对 n_kv_heads 严格线性。每砍一半 KV 头，每 token 的 KV 显存就砍一半，能塞进显存的并发请求翻一倍。
IV

为什么共享得起

第一次见 GQA，反应都是"这能行吗？"——把 8 个 query 头挤到同一份 K、V 上去算 attention，难道不会丢信息？事实是：基本不会。可以从两个角度理解。

一、Q 是问题，KV 是世界状态

每个 query 头是一种提问视角：有的关心"上一个动词在哪里"，有的关心"主语指代谁"。它们差别很大，需要保留。但被它们读取的 K（"我是什么 token、出现在哪里"）和 V（"我携带的信息"）是token 自身的属性——同一个 token 的语义、位置、句法角色，对所有提问者来说都是同一份事实。

MHA 等于让每个提问者各自抄一份世界状态，再各自做笔记。GQA 是让一组提问者共享同一份世界状态，但各自的提问方式照旧。注意力的多样性来自 Q，不是 KV——所以省 KV 不太伤模型质量。

二、训练时就告诉它要共享

GQA 不是推理期 hack。模型在训练时就用 grouped 结构，K、V 投影矩阵从一开始就是窄的，组内 query 头被迫学会从同一份 KV 里挑出有用信号。Llama 团队的做法是把现成的 MHA checkpoint 做 mean-pool，再继续训练一小段，几乎零损失就完成迁移。换句话说，模型会主动适应这把刀。

取舍 MQA（n_kv = 1）在小模型上偶尔伤质量，特别是长上下文。GQA 留 4–8 组就能覆盖绝大多数 quality vs. memory 的甜点——这正是工业界几乎一致的选择。

带走五件事，写成你脑子里的速查表——

① KV cache 跟 n_kv_heads 严格线性。砍一半，KV cache 砍一半，能塞下的并发请求直接翻倍，decode throughput 跟着翻倍——前提是带宽真的是瓶颈（多数情况下是的）。

② 砍的是 K、V 投影，不是 Q。Query 头数保留，模型的"提问多样性"不变，所以质量下滑很小。

③ MQA 是激进端，GQA 是甜点，MHA 是奢侈品。工业界普遍选 GQA-4 或 GQA-8——既拿到 8× 显存收益，又没冒 MQA 的质量风险。

④ GQA 必须训练时启用。不能在推理时把 MHA 的 K、V 投影"压扁"硬塞——必须重新训练或用 mean-pool checkpoint conversion。

⑤ 它和 PagedAttention 是叠加的。GQA 让每个 token 的 KV 块更小，PagedAttention 让这些块不浪费——两个杠杆一起拉，才有 vLLM 那个 throughput 数字。

下一步通向 Multi-head Latent Attention（DeepSeek-V2 的 MLA）——同一把刀的进阶版：不是共享 KV 头，而是把 KV 投影到一个低秩潜空间里再缓存。GQA 是"少存几份"，MLA 是"用更便宜的表示存"，思路一脉相承。
