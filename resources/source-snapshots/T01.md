# T01 可验证事实清单（Source Snapshot）

> 抓取日期：2026-06-07。本文件支撑《NVIDIA vs 昇腾 AI Infra 栈全景》正文、来源与交互 demo 的事实边界。

## 1. 已确认事实

### NVIDIA TensorRT-LLM Documentation

来源：https://docs.nvidia.com/tensorrt-llm/

- TensorRT-LLM 是 NVIDIA 的 LLM 推理优化与部署文档入口
- 覆盖 serving、KV cache、量化、多 GPU 等能力

### NVIDIA Dynamo Introduction

来源：https://docs.nvidia.com/dynamo/v1.0.0/getting-started/introduction

- Dynamo 面向分布式推理服务
- 覆盖 disaggregated serving、KV-aware routing、KV offloading

### What Is CANN

来源：https://www.hiascend.com/document/detail/en/canncommercial/800/quickstart/quickstart/quickstart_18_0004.html

- CANN 向上支持主流 AI 框架，向下服务昇腾 AI 处理器
- CANN 包含图编译、运行时、算子开发等能力

### MindIE LLM Introduction

来源：https://www.hiascend.com/document/detail/en/mindie/230/LLMframe/llmdev/mindie_llm0001.html

- MindIE LLM 面向昇腾大模型推理
- 文档列出 Continuous Batching、PageAttention、FlashDecoding 等推理能力

## 2. 当前 demo 的教学假设

- 指标数值用于交互教学演示，不代表任何真实集群 benchmark。
- 动画中的 block、tile、worker 数量为概念示意，真实部署需以硬件、版本和流量画像实测为准。
