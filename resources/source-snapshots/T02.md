# T02 可验证事实清单（Source Snapshot）

> 抓取日期：2026-06-07。本文件支撑《KV Cache 与 PagedAttention》正文、来源与交互 demo 的事实边界。

## 1. 已确认事实

### TensorRT-LLM KV Cache System

来源：https://nvidia.github.io/TensorRT-LLM/features/kvcache.html

- KV cache 是推理系统中的核心内存资源
- 文档覆盖 KV cache 复用、eviction、offload 等机制

### NVIDIA TensorRT-LLM Documentation

来源：https://docs.nvidia.com/tensorrt-llm/

- TensorRT-LLM 是 NVIDIA 的 LLM 推理优化与部署文档入口
- 覆盖 serving、KV cache、量化、多 GPU 等能力

### NVIDIA Dynamo Introduction

来源：https://docs.nvidia.com/dynamo/v1.0.0/getting-started/introduction

- Dynamo 面向分布式推理服务
- 覆盖 disaggregated serving、KV-aware routing、KV offloading

## 2. 当前 demo 的教学假设

- 指标数值用于交互教学演示，不代表任何真实集群 benchmark。
- 动画中的 block、tile、worker 数量为概念示意，真实部署需以硬件、版本和流量画像实测为准。
