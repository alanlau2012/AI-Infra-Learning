# T04 可验证事实清单（Source Snapshot）

> 抓取日期：2026-06-07。本文件支撑《Ascend C 算子流水线》正文、来源与交互 demo 的事实边界。

## 1. 已确认事实

### Ascend C Operator Development

来源：https://www.hiascend.com/document/detail/en/canncommercial/850/opdevg/

- Ascend C 是 CANN 算子开发主线
- 文档覆盖硬件架构、编程模型、API、算子实现与调优

### Ascend C AI Core Architecture

来源：https://www.hiascend.com/document/detail/en/canncommercial/850/opdevg/Ascendcopdevg/atlas_ascendc_10_0008.html

- Ascend C 文档解释 AI Core 相关硬件结构
- 适合支撑 GM、Local Memory、Cube/Vector/Scalar 等教学内容

### Ascend C Programming Paradigm

来源：https://www.hiascend.com/document/detail/en/canncommercial/850/opdevg/Ascendcopdevg/atlas_ascendc_10_0016.html

- Ascend C 算子通常围绕数据搬运、计算、写回组织流水
- 支撑 CopyIn、Compute、CopyOut 动画解释

### CANN Commercial Edition Documentation

来源：https://www.hiascend.com/document/detail/en/canncommercial/850/index/index.html

- CANN 是昇腾异构计算基础软件栈的文档入口
- 覆盖开发、编译、运行、算子与 API 文档

## 2. 当前 demo 的教学假设

- 指标数值用于交互教学演示，不代表任何真实集群 benchmark。
- 动画中的 block、tile、worker 数量为概念示意，真实部署需以硬件、版本和流量画像实测为准。
