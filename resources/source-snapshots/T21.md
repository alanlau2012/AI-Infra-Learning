### 1.2 DeepSeek V4 注意力架构（CSA + HCA + Lightning Indexer）

来源：HF 官方博客 <https://huggingface.co/blog/deepseekv4>（直接引用原文）。

**层排布（V4-Pro）**：
- 共 **61 层**
- **Layer 0–1**：仅 HCA
- **Layer 2–60**：CSA 与 HCA 交替（alternating）
- 末尾 MTP 块：仅 sliding-window

**CSA（Compressed Sparse Attention）**：
- 沿序列维做 **4× 压缩**，方法是 **softmax-gated pooling + 学到的位置偏置**（learned positional bias）
- 在 4× 压缩后的 KV 块上，由 Lightning Indexer 选 top-k 块再做 attention
- 每个 attention 都附带一条 **sliding-window** 分支保留 recency

**HCA（Heavily Compressed Attention）**：
- 沿序列维做 **128× 压缩**
- 在 128× 压缩后的短序列上做 **dense MQA**（不再做稀疏 top-k 选择）
- 提供"廉价的全局视野"

**Lightning Indexer**：
- 跑在 **FP4** 精度
- 用 **ReLU-scored multi-head dot product** 给候选块打分
- 每个 query 选 **top-k 个压缩块**做精确 attention
- top-k 的 k 值 / 压缩 sliding-window 的具体长度：**官方博客和模型卡均未公开数字**（必须用 `[!ASSUMPTION]`）

### 1.3 DeepSeek V4 量化方案

来源：HF V4-Pro 模型卡 + HF 官方博客。

**KV 存储**：
- **大部分 KV entry → FP8**
- **RoPE 维度 → BF16**（因为 RoPE 对低精度更敏感）
- **Lightning Indexer 权重 → FP4**

**模型权重**：
- Instruct 模型：**MoE expert 权重 → FP4**，其它权重 → FP8
- Base 模型：FP8 throughout

**HF 模型卡 Tensor Type 字段**：BF16, I64, F32, F8_E8M0, F8_E4M3, I8

### 1.4 DeepSeek V4 效率收益（vs DeepSeek-V3.2，1M 上下文）

来源：HF V4-Pro 模型卡（直接引用原文："In the 1M-token context setting, DeepSeek-V4-Pro requires only 27% of single-token inference FLOPs and 10% of KV cache compared with DeepSeek-V3.2"）+ HF 官方博客。

| 指标 | V4-Pro vs V3.2 | V4-Flash vs V3.2 |
|---|---|---|
| 单 token 推理 FLOPs | 27% | 10% |
| KV cache | 10% | 7% |

**额外对比基准**（HF 官方博客）：
- V4 KV cache vs **传统 grouped query attention（8 heads, BF16）** ≈ **2%**
- 这是审稿1.md H3 提到的"2% KV cache figure"的真正口径——**对比基准是 GQA-8H/BF16，不是 V3.2**。

### 1.5 DeepSeek V4 训练与其它架构组件

来源：HF V4-Pro 模型卡。

- **训练 token 数**：**32T+** "diverse and high-quality tokens"
- **mHC（Manifold-Constrained Hyper-Connections）**：增强常规残差连接
- **Muon Optimizer**：用于更快收敛和训练稳定性

**未公开的项**（需要在正文中保留为定性或用 `[!ASSUMPTION]`）：
- 单 layer 内 MoE 总专家数 / 激活专家数
- Lightning Indexer 的 top-k 具体数字
- Sliding window 的具体长度
- 训练硬件（H100 / H800 / 国产 NPU 等）

### 1.6 DeepSeek V3.2-Exp（V4 的对照基准）

来源：HF 模型卡 <https://huggingface.co/deepseek-ai/DeepSeek-V3.2-Exp> + arXiv 论文 <https://arxiv.org/abs/2512.02556>。

- 发布日期：2025-09-29（exp）/ 2025-12（V3.2 正式版）
- **DSA（DeepSeek Sparse Attention）**：把 attention 复杂度从 O(L²) 降到 O(L·k)
- DSA 由两部分组成：
  1. **Lightning Indexer**（V4 沿用并升级到 FP4）
  2. **Fine-grained Token Selector**
- 性能：与 V3.1-Terminus 相当
- 模型规模（来自配置文件 `config_671B_v3.2.json`）：约 **671B** 总参（与 V3 同级，复用底座）
- 专家数：**256**（来自模型卡转换脚本 `EXPERTS=256`）
- Context：**128k**
- 量化：FP8（标签）+ BF16（SGLang 推理支持）

### 1.7 DeepSeek V3 (基础对照)

来源：DeepSeek-V3 Technical Report <https://arxiv.org/abs/2412.19437>。

- 671B 总参 / 37B 激活
- **MLA（Multi-head Latent Attention）**：注意力头数 nh=128，每头维度 dh=128，KV 压缩维度 dc=512
- DeepSeekMoE 架构
- 显著降低 KV cache（论文与多篇分析声称约 -93% vs 标准 MHA）

### 1.8 DeepSeek V4 推理框架支持

来源：
- HF 官方博客提到 SGLang Day-0 支持
- vLLM PR / DeepSeek-V3.2-Exp GitHub 仓库提到 vLLM 集成
