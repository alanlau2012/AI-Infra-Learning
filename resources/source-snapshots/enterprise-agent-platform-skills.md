## 核心定位

Enterprise Agent Platform Builder 的本质不是普通 AI 应用负责人，而是在大型企业受限环境中，把 LLM 从模型能力变成企业级生产力基础设施的人。

该角色横跨基础设施、模型服务、Agent Runtime、Skill 生态、业务系统集成、安全治理、产品工作台和组织推进。
